# Max Estates 59 Landing Page

An ultra-luxury landing page designed for **Max Estates Sector 59**, Gurugram (Bungalows in the Sky).

## 🌟 Features
- **Premium Design**: Sleek, modern aesthetic designed to match the high-end luxury brand of Max Estates.
- **Lead Generation**: Seamless user experience with a floating CTA and a responsive popup modal form for capturing leads.
- **Thank You Page**: Integrated `thank-you.html` redirect upon successful form submissions.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop devices.
- **Vanilla Tech Stack**: Built purely with HTML, CSS, and JavaScript for optimal performance and no heavy framework dependencies.

## 🚀 Setup Instructions
To run this project locally, simply clone the repository and serve it using any local static file server.

### Using Node.js
```bash
npx http-server . -p 8080
```

### Using Python
```bash
python3 -m http.server 8080
```

Then, open your browser and navigate to `http://localhost:8080`.

## 📁 File Structure
- `index.html`: The main landing page.
- `thank-you.html`: Lead capture success page.
- `assets/css/style.css`: All styling rules and CSS variables.
- `assets/js/main.js`: Scroll behaviors, modal logic, and form handling.
- `assets/images/`: Contains all static image assets.
